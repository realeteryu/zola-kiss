**Zola-Kisse** is a minimalist, lightweight, and responsive blog theme ported to [Zola](https://www.getzola.org/) — a fast static site generator written in Rust. It is inspired by the original [Klisé](https://github.com/piharpi/jekyll-klise) theme for Jekyll, redesigned from the ground up to use native Tera templates without external dependencies.

### Key Features

* **Zero Dependencies:** Built purely with native Zola features, Tera templating, and clean SCSS.
* **Dark & Light Mode:** Automatic system preference detection with a manual toggle and persistent state via `localStorage`.
* **Fast & Accessible:** High Lighthouse scores, semantic HTML, responsive typography, and keyboard-friendly navigation.
* **Built-in Essentials:** Native Table of Contents, taxonomy support (tags), RSS feed generation, and an integrated image lightbox.
